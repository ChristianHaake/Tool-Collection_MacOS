# Automatisierung und Regelwerk

Dieses Hintergrunddokument beschreibt die Pflege der Sammlung. Es richtet sich an Mitwirkende und gehört nicht zum regulären Leseweg.

## Redaktionelle Regel

Empfohlen werden nur Tools, die aus praktischer Nutzung sinnvoll erscheinen und deren Empfehlung kurz begründet werden kann. Die Sammlung ist kuratiert, keine vollständige Marktübersicht und kein objektives Ranking.

## Format einer Empfehlung

```md
### [Toolname](https://link-zur-primaerquelle)

Ein bis zwei kurze Sätze: wofür das Tool gedacht ist und was es auszeichnet.
```

Die Beschreibung ist knapp und auf Deutsch gehalten. Der Link zeigt nach Möglichkeit auf die Primärquelle (Projektseite oder Repository).

## Technische Statusprüfung

Statusdaten werden künftig automatisiert geprüft. Erfasst werden nur überprüfbare Fakten:

- Erreichbarkeit der offiziellen Projektseite
- letzte veröffentlichte Version oder letzter Release
- Aktivität eines offiziellen Repositories
- Lizenz
- macOS-Support
- Preis- oder Tarifangaben, soweit öffentlich verfügbar

Die technische Prüfung beurteilt nicht, ob ein Tool weiterhin empfehlenswert ist. Das bleibt eine redaktionelle Entscheidung.

## Synchronisation zwischen Plattformen

Plattformübergreifende Tools werden in beiden Repositories mit derselben Kategorie, Beschreibung und Verlinkung geführt. Werkzeuge mit echtem Plattformbezug bleiben ausschließlich in der passenden Sammlung.
